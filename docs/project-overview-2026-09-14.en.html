AI-KOL-System — Project Overview

As of 2026-09-14 · 82 commits · source: this repo itself (git log, tools/selftest, direct file counts)

1 · Project structure

① BRAIN persona_brain.py + Ollama (Qwen2.5-7B, fine-tuned for Sofia) → ② VOICE CosyVoice 2 / GPT-SoVITS + RVC timbre pass → ③ FACE LiveTalking + LivePortrait/wav2lip, lip-sync at 25fps → ④ STREAM WebRTC / OBS / RTMP

Single source of truth: kols/<id>/profile.json — personality, language, voice, face and sales role are all read from it. Adding a character means adding a folder, not rewriting code.

Key directories

  • kols/ — 10-character DB + 3 shared voice presets (654 MB, mostly images/voice/video)
  • datasets/ — LLM training data + raw source material (12 MB)
  • tools/ — 12 modules: chat, livestream, llm_train, tts_train, voice_crawl, voice_eval, livetalking, dashboard, selftest, studio, report, talking_web
  • finetune/base/ — base models Qwen2.5-7B-Instruct + Qwen3-8B (30 GB, gitignored, never pushed)

Running apps (ports)

  • 8770 Dashboard · 8772 Selftest (full-system checks, --cli)
  • 8777 Livestream (stage, auto tone-picking) · 8779 1:1 Chat (remembers each viewer)
  • 9880/9881 GPT-SoVITS / CosyVoice 2 · 8010 LiveTalking · 11434 Ollama

3 · Hardware

Serving machine (local)

  • GPU RTX 5070, 12 GB VRAM (sm_120, native bf16) — the hard ceiling for the whole system
  • 7B LLM (~4.7 GB) + voice + avatar just fit in 12 GB; not enough to run them comfortably in parallel or to train lip-sync in-house (needs 23–30 GB)

This session's machine (training/cluster)

  • GPU Tesla V100-SXM2-16 GB (sm_70, driver 550.163, CUDA 12.4, torch 2.8.0+cu128)
  • No native bf16 → train_lora.py was just patched to auto-detect bf16/fp16, so it runs on both machines

4 · What has been done

Voice

  • 5 GPT-SoVITS fine-tuned voices, verified as 5 distinct speakers (ERes2NetV2)
  • Sofia moved to CosyVoice 2 instruct mode; RVC runs as a resident timbre pass (~1s instead of 6.4s)
  • A human-trained RVC model was tried and rejected — didn't hold up
  • Measured: TTS can't sing (pitch range narrows) → solved with a prebuilt song library + RVC instead

Brain & safety

  • QLoRA on Qwen2.5-7B; retrained across several passes: on real answers, on humour, on banter
  • Guards enforced in code, not prompt — measured that prompting alone wasn't enough; 13 test cases, 0 violations once code rules were added
  • Latest patches: block invented addresses, block denying relationship status, fix a _GREETING regex that was eating the first word of a reply
  • Append-only reply-approval queue that survives a crash; every profile runs in suggest mode

Latency & infra

  • Measured that 89% of latency is the voice, not the LLM (0.8s LLM / 6.8s TTS)
  • unload_brain(): evicts the LLM from VRAM before rendering voice → RTF 1.93→0.87
  • Renders in sentence chunks, publishes as soon as the first audio exists; the live room drives the avatar off the real waveform
  • Renamed the character Sofia Vargas → Sofia Hsu, Taiwan canon; just finished cleaning up the training data and a leftover old name in kols/index.json
Still open: replies are stiff (7B model ceiling + training data distilled from itself); 4/10 characters have no images yet; wav2lip is on a research-only license (needs to move to MuseTalk before commercial use).
