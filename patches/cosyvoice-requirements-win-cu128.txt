# CosyVoice 2 requirements, adjusted for this box (Windows, RTX 5070 / Blackwell sm_120).
#
# Two changes from upstream `CosyVoice/requirements.txt`:
#
#   1. torch/torchaudio pins REMOVED. Upstream pins 2.3.1 on a cu121 index — the same pin
#      that already had to be replaced for GPT-SoVITS and LiveTalking, because cu121 wheels
#      carry no sm_120 kernels and a 50-series card cannot run them. Install torch first,
#      from the cu128 index, then this file:
#
#        .venv\Scripts\python.exe -m pip install torch torchaudio \
#            --index-url https://download.pytorch.org/whl/cu128
#        .venv\Scripts\python.exe -m pip install -r patches\cosyvoice-requirements-win-cu128.txt
#
#      Order matters: several packages below declare a torch dependency, so installing them
#      first can pull a CPU or cu121 build over the top of the working one. Re-check with
#      `torch.cuda.is_available()` afterwards.
#
#   2. The cu121 extra-index-url is dropped, so nothing silently resolves back to it.
#
# One more step is needed before this file will install at all. `openai-whisper==20231117`
# has a setup.py that imports `pkg_resources`, which setuptools 81+ no longer ships, so its
# isolated build fails with ModuleNotFoundError and pip aborts the whole resolve — nothing
# gets installed, not just whisper. It cannot simply be dropped: `cosyvoice/cli/frontend.py`
# imports `whisper` on the inference path. Install it out of isolation first:
#
#        .venv\Scripts\python.exe -m pip install "setuptools<81" wheel
#        .venv\Scripts\python.exe -m pip install --no-build-isolation openai-whisper==20231117
#
